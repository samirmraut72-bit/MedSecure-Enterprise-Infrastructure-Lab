# 07 — Security & Hardening

Security is treated as a layer across the entire environment rather than as a separate product.

## Current controls

- VLAN segmentation and Layer-2 security
- Least-privilege design
- Microsoft Entra MFA
- Application roles and RBAC
- Security logging
- CSRF protection and secure headers in MedSecure
- Login rate limiting and patient-record isolation

## Next phase

The next major lab phase is authorised security testing of this same environment:

**Discover → test → document finding → remediate → retest**

Planned exercises include network exposure checks, web-application access-control testing, service discovery and validation that remediation actually reduces the attack surface.
