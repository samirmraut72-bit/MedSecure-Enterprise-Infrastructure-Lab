# 05 — Hybrid Identity, Entra ID & Intune

## What it demonstrates

- Microsoft Entra Connect synchronisation
- Hybrid-joined Windows device
- Microsoft Entra users and application roles
- MFA for workforce access
- Microsoft Intune enrollment and policy deployment
