# 06 — MedSecure Business Application

MedSecure is the application layer that consumes the identity and infrastructure services built in the rest of the lab.

## What it demonstrates

- Microsoft Entra workforce SSO
- MFA during workforce sign-in
- Nurse, Doctor and Administrator application roles
- Application-level RBAC and least privilege
- Separate patient authentication
- Security logging and route-level access controls

**Live demo:** https://medsecure-sam-git-main-project-beyond.vercel.app
