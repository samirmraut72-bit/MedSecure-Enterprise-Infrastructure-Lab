# 02 — Windows Server & Active Directory

This section shows the Windows infrastructure behind the MedSecure environment.

## What it demonstrates

- Windows Server 2022 domain services
- Active Directory users, groups and organisational structure
- DNS zones and centralised name resolution
- Domain identities used as the foundation for hybrid identity

The deep technical build remains in the [Windows Server / AD / Entra / Intune repository](https://github.com/samirmraut72-bit/Junior-Systems-Administrator-Windows-Server-AD-Entra-ID-Intune-Lab).
