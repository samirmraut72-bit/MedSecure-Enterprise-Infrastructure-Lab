# 03 — GPO & Endpoint Management

This section shows how user and device settings can be centrally controlled rather than configured manually one machine at a time.

## What it demonstrates

- Group Policy structure and linking
- Security and user restriction policies
- Domain client configuration
- Intune policy deployment as the cloud-management layer
