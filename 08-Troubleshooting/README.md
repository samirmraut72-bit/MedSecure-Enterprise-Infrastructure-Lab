# 08 — Troubleshooting

A major purpose of this project is learning how to isolate faults across multiple layers instead of treating each technology separately.

## Troubleshooting areas already encountered

- VLAN, trunk and routing validation
- DHCP and gateway reachability
- Active Directory OU placement and GPO scope
- Hybrid join and Entra Connect synchronisation
- Intune auto-enrollment and licensing/entitlement issues
- Stale identity/application-role claims
- Application authentication and session behaviour

## Working method

**Symptom → identify layer → collect evidence → test assumption → change one thing → verify result → document**

This section will continue to grow as new faults are intentionally introduced and resolved during the security-testing phase.
